For GitHub Pages:
1. Upload the CONTENTS of this folder to a GitHub repository.
2. In GitHub: Settings > Pages.
3. Deploy from branch: main, folder: / (root).
4. GitHub will provide a working github.io address.
5. A custom domain such as northglenhistory.com.au can then be connected in Pages settings.

IMPORTANT: the suggested custom domain is not registered automatically.
